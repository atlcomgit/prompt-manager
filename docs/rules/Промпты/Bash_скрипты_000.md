# Bash скрипты

Виджет находится в панели «Обзор» открытого промпта. Его можно переместить, свернуть или скрыть через меню виджетов.

## Как пополняется список

- При первом раскрытии без сохранённого каталога, смене папок рабочего пространства и по кнопке повторного поиска виджет находит `*.sh` и `*.bash` во всех папках рабочего пространства. Поиск пропускает `.git`, `node_modules`, `vendor`, `.venv`, `build`, `dist`, `out`, `out-tests` и служебные каталоги `.vscode/prompt-manager`. Область автоматических записей — «Проект».
- Повторное открытие читает готовый каталог, в том числе пустой. Панели делят снимок списка. Изменение каталога или файла обновляет виджет. Перед запуском расширение заново проверяет доступность выбранного файла. После перезапуска прошлые признаки доступности проверяются в фоне, а Git уточняет группы по мере готовности.
- Каждый обнаруженный путь добавляется один раз. Повторный поиск сохраняет вручную заданное название, историю, исключённые пути и добавленные вручную файлы. Пропавший файл остаётся в списке с отметкой «Недоступен». Кнопка запуска выключена, путь можно исправить.
- Ссылка с именем `.sh` или `.bash` может вести на файл без расширения. Например, если его первая строка — `#!/bin/bash` или `#!/usr/bin/env bash`, файл доступен для запуска, ручного добавления и редактирования. Битая ссылка помечается как недоступная.
- «Убрать из виджета» запоминает выбранный путь. Если в другом окне запись успели привязать к другому скрипту, старое подтверждение утрачивает силу. Файл остаётся на месте. Вернуть скрытую запись вместе с историей можно через «+» с тем же путём в той же области.
- Для ручного добавления можно выбрать файл через диалог или ввести путь, в том числе из папки, исключённой из автопоиска. Относительный путь отсчитывается от первой папки рабочего пространства. Глобальная запись хранит полный путь на машине, где работает расширение, и доступна в других проектах на этом хосте.
- Метаданные обеих областей лежат в отдельных файлах `bash-scripts.json`. Для проекта это каталог хранения промптов, для глобальной области — `~/.vscode/prompt-manager`. Копия записи в другой области имеет собственную историю. При ошибке одного каталога виджет показывает предупреждение и доступные строки второй области. Настройки раскладки виджета участвуют в Settings Sync.
- Права нового проектного файла `bash-scripts.json` определяют папка хранения и настройки ОС. В Linux глобальный файл создаётся с правами `0600`. При обновлении существующего файла сохраняются владелец и права, включая ACL. Для файла с несколькими жёсткими ссылками или другим владельцем виджет обновляет содержимое под блокировкой. Такая запись сохраняет все имена файла, но принудительное завершение процесса во время записи может прервать её.

## Группы проектов

Скрипт попадает в ближайшую по пути папку рабочей области или открытый Git-репозиторий. Так у вложенного репозитория появляется собственная группа. Папки с одним названием различаются полным путём. Пути внутри проекта отсчитываются от его корня. Если все скрипты проекта лежат в одной папке, в строках достаточно имён файлов. Если папок несколько, у каждой есть заголовок. Когда скрипты лежат и в общей папке, и в её подпапке, заголовок первой показывает путь от корня проекта, например `.vscode/bash`, а второй — имя подпапки, например `git`. Фильтрация сохраняет заголовки и учитывает полный путь. Пути в строках выровнены по левому краю и показаны приглушённым цветом без фона. В широкой панели у путей своя колонка, в узкой путь помещается под названием. Полный путь доступен в подсказке. Глобальную запись внутри проекта отмечает значок глобуса. Для остальных файлов предусмотрены группы «Вне проектов» и «Глобальные скрипты».

Заголовок с названием и числом скриптов раскрывает группу. Кнопка в шапке виджета сворачивает или раскрывает все видимые группы сразу. По умолчанию в каталоге до восьми записей группы раскрыты, в большем каталоге свёрнуты. Явный выбор по каждой группе сохраняется в настройках «Обзора» и восстанавливается после сканирования и повторного открытия. Поиск и фильтры временно раскрывают совпадения. Изменения раскрытия во время поиска действуют до смены фильтра. Длинный список и история запусков прокручиваются вместе с панелью «Обзор».

## Редактирование

Название в списке, путь и текст редактируются в одном окне. По умолчанию его размер 820 × 560 пикселей. После перетаскивания нижнего правого угла редактор запоминает размер локально и при открытии вписывает его в видимую область виджетов. Диалог остаётся по центру. Во время чтения файла и подготовки редактора в поле кода виден индикатор загрузки. Кнопка «Загрузить» читает выбранный файл. Для нового пути в существующей папке открывается пустой текст. После смены пути нужно загрузить целевой файл. Смена пути перепривязывает запись, исходный файл остаётся на месте.

Редактор подсвечивает синтаксис Bash, активную строку и парные скобки. Ctrl+F открывает поиск и замену, Ctrl+G переводит к строке, Ctrl+Z отменяет правку. Внизу видны кодировка, окончания строк и позиция курсора. Перенос длинных строк можно отключить. По умолчанию Tab переходит к следующему полю. Кнопка «Tab» включает ввод отступов, Escape возвращает переход между полями. Кодировка UTF-8 с BOM и исходные окончания строк сохраняются при редактировании.

Пока загружается файл, можно редактировать название или сразу закрыть окно клавишей Escape. Запоздалый ответ относится только к тому окну, в котором началось чтение. Ответ расширения и смена числа колонок сохраняют выбранное поле. При закрытии диалога восстанавливаются фокус и выделение в поле, из которого пользователь открыл редактор мышью. При открытии с клавиатуры фокус возвращается на кнопку открытия. Пока пользователь печатает в другом окне VS Code, обновление «Обзора», чтение файла и ответ на сохранение оставляют ввод в выбранном окне. Исходные название, путь и текст можно закрыть без подтверждения, в том числе после повторного выбора того же проектного файла.

При ручном добавлении переключение между «Проект» и «Глобальная» сохраняет введённый текст для того же файла. Если после нажатия «Сохранить» виджет сменил колонку, подтверждение записи относится к отправленной версии черновика. Успешный ответ закрывает сохранённую версию, сообщение об ошибке оставляет правки доступными для повторной попытки.

Запись на диск происходит по «Сохранить» или Ctrl+S. Закрытие изменённого черновика предлагает сохранить, продолжить редактирование или закрыть без сохранения. Перед заменой изменённого текста при повторном чтении требуется подтверждение. Если другая программа изменила файл или у него есть несохранённые правки в редакторе VS Code, виджет сообщает о конфликте. Текст UTF-8 до 1 МиБ редактируется внутри виджета. Для больших файлов и других кодировок диалог предлагает открыть штатный редактор VS Code. Такие скрипты тоже можно добавлять и запускать. Изменение одного названия у пропавшего скрипта сохраняет запись с отметкой «Недоступен».

Содержимое существующего скрипта обновляется в том же файле. Его владелец, права доступа и жёсткие ссылки сохраняются. При ошибке записи виджет пытается восстановить исходный текст. При принудительной остановке процесса во время записи файл может сохраниться частично. Виджет распознаёт несохранённые правки VS Code, даже если файл открыт через другую символьную или жёсткую ссылку. Скрипт со специальными битами setuid или setgid можно изменить в штатном редакторе.

## Запуск и история

В доверенной рабочей области кнопка ▶, Enter на этой кнопке или двойной щелчок по названию запускают Bash в отдельной интерактивной вкладке редактора VS Code. Открытым остаётся «Обзор». Файл передаётся как один аргумент, поэтому пробелы и кавычки в пути допустимы. Bash должен быть установлен на хосте расширения. Для файла внутри проекта рабочая папка терминала — соответствующий корень workspace, для внешнего файла — его папка.

Рядом с названием доступны постоянные кнопки истории, редактирования и скрытия. Пока оболочка отслеживает запущенную команду, вместо кнопки запуска вращается серый индикатор, а рядом с часами каждую секунду обновляется затраченное время. По завершении код 0 окрашивает длительность, точку и полосу истории в зелёный цвет, любой другой числовой код — в красный. Неизвестный результат отображается нейтральным цветом. Без интеграции оболочки выполнение команды в терминале доступно, но точное время и код завершения могут отсутствовать. Для нового скрипта и запуска с неизвестной длительностью отображается прочерк. Нажатие на часы раскрывает вертикальную историю до 50 последних запусков. В каждой записи указаны местные дата и время старта, результат и длительность, если она известна. Для выполняющегося скрипта в строке и в истории 100% соответствуют длительности последнего запуска этого скрипта, завершённого до его старта, с известной положительной длительностью. Полоса остаётся полной при превышении этого времени, счётчик продолжает идти. При отсутствии измерения показывается движущийся индикатор. В истории завершённых запусков самой долгой известной длительности соответствует полная полоса, остальные завершённые запуски пропорциональны ей. Фильтр «Недавние» располагает скрипты по времени запуска.

Длительность считается от отправки команды до события её завершения от оболочки. Для старых записей достаточно времени окончания и числового кода выхода. Если пользователь закрыл терминал и оболочка не прислала событие завершения команды, история показывает закрытие терминала и неизвестную длительность.

Время запуска фиксируется при отправке команды. При отказе открыть терминал или передать команду история сохраняет прежнее состояние. Если каталог истории доступен только для чтения, команда всё равно отправляется, а VS Code показывает отдельное предупреждение. Создание и удаление файлов `.sh` и `.bash` в рабочей папке обновляет доступность строк. При отказе запуска отсутствующего файла обновляется и строка внешнего скрипта.
