# Общий каталог AI-моделей

## Загрузка и использование

- `AiService` один на Extension Host. При активации `initializeModelCatalog` запускает фоновый запрос
  `vscode.lm.selectChatModels()`; активация и открытие промпта не ожидают его завершения.
- Один снимок объектов `LanguageModelChat` используется полем «Модель ИИ» страницы промпта, настройками Memory,
  подготовкой запуска чата и внутренними AI-сценариями, включая Git Flow. Одновременные обращения ждут одну загрузку.
- «Целевой чат» содержит фиксированный список интеграций и не запрашивает каталог моделей.
- Полный непустой снимок хранится в памяти до изменения каталога или аккаунта. Истечение краткосрочного
  кеша выбранной модели не требует повторного LM-запроса: новый выбор выполняется по общему снимку.
- `vendor`, `id`, `family`, `version` сопоставляются точно, как в селекторе API. Бесплатный резервный выбор
  дополнительно проверяет локальные метаданные стоимости и точный Copilot id, без совпадения по похожему имени.
- Видимость, закреплённые и недавние модели остаются актуальными: пользовательская проекция строится по локальным
  метаданным VS Code. Изменение этих настроек не требует повторного получения API всех моделей.
- Прогрев получает каталог, но не отправляет запросы генерации. Выключенный `promptManager.ai.enabled`
  запрещает внутреннюю генерацию; каталог остаётся нужен для выбора пользовательского чата.

## Обновление и ошибки

- `lm.onDidChangeChatModels`, изменения сессий `github`/`github-enterprise` и завершённая смена аккаунта
  очищают общий и выбранный кеши, затем запускают прогрев. Несколько событий во время RPC объединяются.
- Поколение каталога защищает от запоздалых ответов: результат старого аккаунта не публикуется и не используется
  для нового запроса. Незавершённый старый RPC сначала заканчивается, затем выполняется актуальная загрузка.
- После загрузки открытые редактор и Memory получают обновлённый список, даже если первоначальный ready-таймаут
  уже истёк. Закрытая панель не получает поздний результат; для редактора проверяется синхронный набор живых панелей.
- При ошибке полного запроса допускается резервный каталог Copilot. Пустой или неполный снимок кешируется
  на 1,5 секунды; выполняются не более двух фоновых повторов с задержками 1,5 и 5 секунд.
  После их исчерпания следующий запрос по истечении срока или новое событие снова допускает загрузку.
- Холодный/неполный каталог сохраняет адресный выбор основной модели и бесплатных кандидатов.
  Полный актуальный каталог не запрашивается повторно из-за отсутствия конкретного id.
- `LanguageModelError.NotFound` сбрасывает снимок с удалённым объектом. Неуспешная генерация автоматически
  не повторяется: для Git Flow продолжает действовать штатный резервный Copilot.
- `dispose` снимает подписки, очищает кеши и таймер повторов. Уже начатый LM RPC отменить нельзя;
  его поздний результат или ошибка не вызывают публикацию, новый RPC или генерацию.

## Проверки и диагностика

- `tests/aiService.test.ts`: совместный прогрев picker/free-list/нескольких commit, переиспользование после 60 секунд,
  актуальность visibility, точный free-only выбор, события аккаунта/каталога, объединение инвалидирований,
  пустой/частичный/ошибочный ответ, ограниченные повторы, NotFound и dispose.
- `tests/editorPanelManager.test.ts`: единичная рассылка после загрузки, поздняя доставка и закрытие панели;
  существующие проверки ready, запуска чата и одиночной/групповой генерации.
- При включённом debugLogging канал Prompt Manager содержит `label=model-catalog result=loaded`
  с числом моделей и длительностью и `result=cache-hit` при выборе из снимка. Эти проверки подтверждают
  отсутствие повторного LM RPC; время реального провайдера измеряется отдельно в Extension Host.
- `tests/promptManagerOutput.test.ts` проверяет прохождение событий каталога через фильтр, включая прямую запись
  AiService в канал; без debugLogging обычные события прогрева и попаданий в кеш подавляются.
- Связанный порядок генераторов и границы ошибок: [Генерация сообщений коммитов](../Git/Генерация_сообщений_коммитов_172.md).
